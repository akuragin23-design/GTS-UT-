# Диагностика взаиморасчётов после перехода 01.07.2026

Запросы предназначены для УТ 11.5.25.105. Они только читают данные и ничего не изменяют.

## Как выполнить

1. Работать сначала только в тестовой базе.
2. Открыть внешнюю обработку «Консоль запросов». Если её нет, запросить её у администратора 1С.
3. Для каждого запроса установить параметры:
   - `НачалоАнализа` — начало периода, за который могли существовать переносимые остатки;
   - `ДатаДоПерехода` — `30.06.2026 23:59:59`;
   - `ДатаПерехода` — `01.07.2026 00:00:00`;
   - `ДатаТекущихОстатков` — текущая дата либо конец проверяемого периода.
4. Сохранить каждый результат в отдельный XLSX с указанным именем.
5. Не перепроводить документы между выполнением запросов.

## Что считать подозрительным

- ненулевой остаток на объекте с `ПометкаУдаления = Да`;
- два и более объекта расчётов с одинаковой аналитикой;
- остаток на объекте `ТолькоОстатки`, который продолжает существовать после погашения;
- один договор представлен несколькими объектами расчётов, созданными одним старым документом;
- движения старого документа относятся к другому объекту расчётов, чем документ переноса;
- сумма на 30.06.2026 вместе с движениями документа переноса не даёт ожидаемую сумму на 01.07.2026.

Дата фактического перепроведения в регистрах накопления не хранится. Для неё потребуется журнал регистрации или история данных. Сначала достаточно пяти выгрузок выше.
